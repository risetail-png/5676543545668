# 橋梁点検PDF リンク追加ツール（データ記録様式 その３-１／その３-２ 版）

「データ記録様式（その３-１）損傷図」と「データ記録様式（その３-２）損傷写真」の間に、
径間番号が一致するページ同士を相互リンクするボタンを自動追加するツールです。

## 使い方

```
pip install pikepdf pypdf Pillow
python bridge_pdf_link_app_sono3.py
```

PDFをドラッグ＆ドロップ（または「追加…」で選択）し、「▶ 処理開始」を押してください。
各PDFと同じフォルダに `_linked.pdf` が保存されます。

## 動作概要

- 径間番号が同じ「その３-１」ページと「その３-２」ページ同士をボタンでリンクします。
- 損傷図（その３-１）の各ページ → 同じ径間の損傷写真ページ全てへのボタン（青、写真番号の範囲を表示）
- 損傷写真（その３-２）の各ページ → 同じ径間の損傷図ページ全てへのボタン（緑、ページ番号を表示）
- 複数径間のPDF（径間番号1、1-1、1-2…）にも対応しています。

## v8/v9（その９↔その１０版）との違い

| 項目 | その９/その１０版 | その３-１/その３-２版（本ツール） |
|---|---|---|
| リンク対象キーワード | `データ記録様式(その９)` / `(その１０)`（半角括弧） | `データ記録様式（その３-１）` / `（その３-２）`（全角括弧） |
| ページ回転 | 想定なし（/Rotate 0 前提） | **/Rotate 90（縦A4を横向き表示）に対応**。ボタン画像・リンク注釈の座標をページの回転角に応じて変換してから描画するよう変更 |
| 径間番号の読み取り | 座標指定セル＋テキスト正規表現の二段構え | 座標指定セルは回転により機能しないため、テキスト正規表現（`起点側 終点側<径間番号>`）に一本化 |
| 先頭ページの様式間ナビ（その１〜その１３） | あり | なし（その３-１/その３-２のリンクのみに特化） |

## 注意事項

- 本ツールは「データ記録様式（その３-１）」「データ記録様式（その３-２）」という文字列がページ内テキストとして
  埋め込まれていることを前提にしています（画像スキャンのみのPDFでは動作しません）。
- 径間番号は各ページの「起点側　終点側　＜径間番号＞　緯度…」という並びから取得しています。
  様式が異なるPDFでは、この部分の正規表現（`get_span_number_fallback`関数）の調整が必要になる場合があります。
